# TenX

Read [shared controls](../../references/controls.md) completely.

Select the earliest phase whose entry evidence is satisfied:

1. [Understand](../understand/SKILL.md): no exact user-approved alignment record.
2. [Investigate](../investigate/SKILL.md): approved alignment exists, but no exact PASS-reviewed investigation.
3. [Slice](../slice/SKILL.md): approved alignment and PASS-reviewed investigation exist, but no exact user-approved slice sequence.
4. [Implement](../implement/SKILL.md): one slice from the user-approved sequence is selected — Slice approval is the implementation authority.

Never reconstruct missing approval from intent, summaries or later work. If evidence changed, return to its owning phase. State the selected phase and why, then read and follow that phase file completely. Load no later phase early.
